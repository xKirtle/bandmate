# Takes are recorded as lossless WAV

Takes are captured as raw audio in the browser (AudioWorklet) and stored as lossless WAV (48 kHz, mono, 24-bit), not as the compressed Opus/WebM the browser's `MediaRecorder` produces by default. The input comes through a real audio interface, so quality is worth keeping. Exact timing makes Latency Offset compensation reliable, and an untouched recording can later be taken into a real DAW. Disk space in the homelab is cheap (~10 MB per minute). Uploaded Beats and Masters stay in whatever format they were uploaded in, and the Mixdown is still exported as MP3.
