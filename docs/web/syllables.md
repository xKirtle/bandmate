# Syllable counts

In Write mode, Bandmate counts the syllables of each line as you type, so you can keep the meter without counting on your fingers: check that verse 2 sings like verse 1, or that an alternate fits where the one it competes with sat.

## Where the counts show

Each line's count sits in a muted column to the left of the line, so the counts line up down a section and you can compare them at a glance. A line that wraps shows its count on its first row.

The counts also show beside each line when you choose between a section's [alternates](/features#write), and on the cards in the Scrapbook, so you can see whether a loose idea fits a section before you move it in.

Read mode doesn't show them: it stays as it was, to play from.

## What's counted

- **Chords aren't**: `[Am]Hello` counts as two syllables.
- **A line of chords alone, or a blank line,** gets no count.
- **A hyphenated word** counts as its parts: "ooh-ooh" counts like "ooh ooh".
- **Words** are looked up in the [CMU Pronouncing Dictionary](https://github.com/cmusphinx/cmudict), which knows over 130,000 English words.

## Estimates

A word the dictionary doesn't know, like slang, a name or "skrrt", is guessed from its spelling. A number in digits, like "24", is counted as it's usually said. Either way, the line's count shows as an estimate, such as `~7`, so you know not to trust it exactly.

The counts are only numbers: nothing flags a line whose meter doesn't match, as you may change the meter on purpose.

## Languages

Bandmate counts in the languages set in the song's details, which start as English. For now, English is the only one it counts.

## Turning them off

**Writing aids**, in the lyric sheet's toolbar in Write mode, turns the counts on and off, for every song. It's on to start with. Each device keeps its own choice, which is also in **Settings**, under **This device**.

## Offline

Everything is worked out on your device, from a dictionary built into Bandmate, so the counts keep up with your typing and work without an internet connection. The first time you write a song in a language, your browser downloads its dictionary from your Bandmate, about a megabyte, and keeps it. While Writing aids is off, it downloads nothing.
